One section per session. The list below defines the next bounded work; split a section further before implementation if needed. Shared acceptance rules: all new records must be included in backups/recovery and safe deletion; stale writes must preserve the user's form; no lossy archive import/export. Portable archives/attachments and full responsive/accessibility/performance/security gates follow these sections.

Current local Podman checks run on ARM64 and do not satisfy x86 verification.
