Spec already covers the required records; no format changes are proposed.

One section per session. The list below defines the next bounded work; split a section further before implementation if needed. A completed section means its stated scope works, not that the whole bible is complete. Each section needs tests/build, tracking updates and a Server commit. Current local Podman checks run on ARM64 and do not satisfy x86 verification.
